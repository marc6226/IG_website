# IG_website

Landingspagina's per dienst van Intergarde. Gewone HTML en CSS, geen bouwstap nodig.

## Opbouw

```
index.html            Overzicht van alle diensten
meldkamer/index.html  Landingspagina meldkamer en alarmopvolging
assets/css/style.css  Gedeelde stijl voor alle pagina's
assets/js/main.js     Tijdelijke afhandeling aanvraagformulier
```

Een nieuwe dienst = een nieuwe map met een `index.html` (kopie van `meldkamer/index.html` als basis) en een extra kaart op `index.html`.

## Bekijken

Open `index.html` in de browser, of zet de repository op Vercel, Netlify of GitHub Pages.

## Vóór livegang

- [ ] Tekst gemarkeerd met `[HAKEN]` invullen (geel gemarkeerd op de pagina)
- [ ] Diensten op de meldkamerpagina controleren
- [ ] Foto's toevoegen
- [ ] Intergarde-huisstijl: logo, kleuren, lettertypes
- [ ] Aanvraagformulier vervangen door HubSpot-formulier (het huidige formulier verstuurt niets)
- [ ] HubSpot-trackingcode en eventueel Leadinfo toevoegen
